# fly-hl-research

Public research scratchpad for two data sources:

- **MaleCNS v1.0** — Google Research / HHMI Janelia male fruit-fly connectome
- **Hyperliquid public market data** — trades, books, funding, open interest, liquidations

## Scope

Compare a small connectome subgraph (vision / looming / mushroom-body loops) against boring baselines on public BTC-PERP features.

Walk-forward only. Costs include fees and funding. No claim of live edge.

## Non-goals

- No private keys, agent wallets, or live order placement in this repo
- Not a Hyperliquid trading bot
- Not financial advice

## Data (public)

- Connectome: MaleCNS v1.0 (CC BY 4.0)
- Hyperliquid: official `info` / websocket APIs and S3 archives (`hyperliquid-archive`, node fills)
